# ミライすごろく

友達とブラウザで遊べる、人生すごろく風のオンラインボードゲームです（2〜6人、CPU追加可）。

## 遊び方
1. ホストがページを開いて名前を入れ「ルームを作る」を押す
2. 表示された招待URLを友達に送る（友達はURLを開いて名前を入れるだけ。アカウント不要）
3. 2人以上そろったらホストが「ゲームを始める」

スタートでは「大学コース」「就職コース」「夢追いコース（ダーツプロ・スポーツ選手・YouTuberなど）」から選べます。
全員がゴールしたら所持金で順位が決まります。

## しくみ
- `index.html` 1ファイルだけで動きます（サーバー不要）。
- 通信は [PeerJS](https://peerjs.com/) を使ったブラウザ同士の直接通信（WebRTC）です。ホストのブラウザがゲームの進行を管理するので、**ホストはゲーム中ページを閉じないでください**。閉じてしまっても、同じブラウザで開き直すと「前回のゲームを再開」できます。
- `?local=1` を付けて開くと、同じPCのタブ同士で動作確認できるテストモードになります。

## 公開
GitHub Pages（Settings → Pages → Branch: `main` / root）で公開できます。
